## Objective

Add the setting that controls whether, and for how long, canonical CT readings persist in
`ct_samples` (`interfaces.md` §1).

## Context

- Storage settings are around `settings.py:184-200`. The raw horizon comment at
  `:186-192` says raw samples are about 88 % of growth. Keep it, and add that
  `retention_days_raw` no longer governs `ct_samples` (ADR-0042).
- Env parsing follows the `get("WM_…", default=str(cfg.…))` pattern at `:355-430`.
- Validation is in `validate()` around `:520-560` and follows the `RETENTION_DAYS_RAW_RANGE`
  pattern at `:525`.
- `to_dict()` is around `:665`. Check whether `redacted()` derives from `to_dict()`; the new
  key must appear in both (the panel's "Configuration (redacted)" uses `redacted()`).

## Steps

1. Add the module constant `RAW_CAPTURE_DAYS_RANGE: tuple[int, int] = (0, 90)` next to the
   other range constants (`:50-64`) and export it if the module has `__all__`.
2. Add the field `raw_capture_days: int = 0` in the Storage block with the docstring
   comment from `interfaces.md` §1.
3. Parse `WM_RAW_CAPTURE_DAYS`. An empty string falls back to the default. Note that the
   neighbouring code uses `or default` patterns that would turn an explicit `0` into the
   default. **0 must be preserved.** Write it explicitly, e.g.
   `raw = get(...); cfg.raw_capture_days = int(raw) if raw not in (None, "") else cfg.raw_capture_days`.
4. Validate: out of range → `problems.append("raw_capture_days must be in 0-90")`.
5. Add `"raw_capture_days"` to `to_dict()`, and to `redacted()` if that is separate.
6. Update the `retention_days_raw` comment as described above. Change no other default.
