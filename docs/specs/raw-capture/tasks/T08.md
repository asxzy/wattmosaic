## Objective

Make the runtime honour `raw_capture_days`: no persistence at 0, and a single off-loop
deletion path for `ct_samples` (`interfaces.md` §4, `design.md` §3.1–3.2).

## Context

- Enqueue: `core/runtime.py:682` `self.persist_queue.put_nowait(("reading", reading))`. The
  writer loop (`:205-224`) and `_persist_batch` (`:226-232`) only handle `"reading"` items.
- Maintenance: `_maintenance_loop` (`:2398-2410`) calls
  `self.db.prune(self.config.retention_days_raw, self.config.retention_days_aggregates)` on the
  loop, then submits `_prune_evidence` and `_prune_derived` to the background executor.
- `_prune_evidence` (`:2300-2345`) contains a `DELETE FROM ct_samples` block (`:2333-2345`)
  keyed on `evidence_raw_retention_days`. Remove it and update the docstring. Keep the
  `apply_evidence_retention` call.
- `submit_background` (`:1779`). See `_prune_derived(self, *, budget=None)` for the
  background-job signature convention.
- Counters are initialised in `main.py:277` (`self.samples_persisted = 0`).
- Invariants: the fast path stays O(1) and never raises; exceptions in background jobs are
  logged and become degraded state, never a crash (CLAUDE.md); long work stays off the
  asyncio loop (ADR-0033).

## Steps

1. `main.py:277`: add `self.raw_capture_purged = 0` beside `samples_persisted`.
2. Gate the enqueue at `:682` on `self.config.raw_capture_days > 0`. Keep everything else on
   that path (ingestion counters, ring updates) unchanged. The check must be a cheap
   attribute read.
3. `_maintenance_loop`: pass `capture_days=self.config.raw_capture_days` to `db.prune` and
   `self.submit_background(self._purge_raw_capture)`.
4. Add `_purge_raw_capture(self, *, budget: Any | None = None) -> None`:
   ```python
   days = self.config.raw_capture_days
   cutoff = None if days <= 0 else self._clock() - timedelta(days=days)
   try:
       result = purge_ct_samples(self.db._conn, self.db._lock, cutoff=cutoff)
   except Exception:  # noqa: BLE001 - degraded, never a crash loop
       log.warning("raw capture purge failed", exc_info=True); return
   self.raw_capture_purged += result.deleted
   if result.deleted:
       log.info("raw capture purge: deleted %d ct_samples rows (done=%s)", result.deleted, result.done)
   ```
   Import `purge_ct_samples` locally (like `_prune_evidence` imports `tiers`) to keep the
   runtime import light. If a `budget` object is provided and exposes a time allowance,
   map it onto `time_budget_s`. Otherwise use the defaults.
5. Remove the `ct_samples` block from `_prune_evidence`.
