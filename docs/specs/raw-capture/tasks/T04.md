# T04: replay from HA recorder history

**Wave:** 1 · **Depends on:** none
**Owner:** `tools/audit/replay_capture.py`, `tools/audit/ha_client.py` (only if strictly needed)
**New file:** `tests/unit/test_replay_ha_history.py`

## Objective

Let `replay_capture.py` take its samples from HA's recorder instead of `ct_samples`, so a
production issue can be replayed with engine raw capture off (`interfaces.md` §7,
`design.md` §3.4).

## Context

- Today the samples come from `load_capture_db` (`replay_capture.py:334`, reads `ct_samples`)
  or `load_capture_jsonl` (`:389`). Both return `Capture(samples=[CaptureSample…], source,
  window_start, window_end, notes)` (`:173-196`). `replay()` (`:558`) consumes a `Capture`.
- `main()` (`:755`) builds `entity_to_ct` from the latest `topology_versions` payload in
  `--db`/`DEFAULT_DB` (`:833-860`), including `aligner_key()` aliases. Reuse it unchanged.
- `ha_client.py` has `HAClient` (aiohttp, `ws_command` at `:122`), `connection_settings()`
  (env `HA_URL`/`HA_HOST`, `HA_TOKEN`) and `fetch_history(client, entity_ids, start=, end=,
  minimal=True)` (`:180`), which wraps `history/history_during_period` with
  `no_attributes=True`. Note that `fetch_history` is defined *after* the
  `if __name__ == "__main__"` block. It still imports fine. Leave it there unless you must
  change it.
- HA compressed rows: `{"s": "<state>", "lu": <epoch float>}`, or `"lc"` when `"lu"` is
  absent. See `tools/audit/derive_state_entities.py:270-310` for a working parser.
- The engine stays read-only toward HA. This is a `tools/` feature and `history/*` is a
  read command. No service calls.

## Steps

1. `load_capture_ha_history(payload, *, entity_to_ct, start, end) -> Capture` (pure):
   - For each entity in the payload, map it to `ct_id` via `entity_to_ct` (try the raw
     id, then `aligner_key(id)`). Unmapped entities are counted in a note.
   - Each row: timestamp = `lu` else `lc` (epoch seconds → aware UTC datetime);
     `value_w = float(s)`. Non-numeric states (`unavailable`, `unknown`, `""`) are skipped
     and counted in a note. Rows outside `[start, end]` are dropped.
   - `CaptureSample(ct_id, entity_id, value_w, state_timestamp=ts, received_at=ts,
     quality="good", repeated=False, sequence=i)`. Sort by `(received_at, ct_id)`.
   - Notes, always explicit:
     - `"received_at = HA last_updated; arrival jitter not available (ADR-0042)"`;
     - per entity with zero rows: `"<entity>: no recorder history (excluded from recorder?)"`;
     - if an entity's first row is more than 1 h after `start`:
       `"<entity>: recorder history starts at <ts> (purge_keep_days?)"`.
   - `source="ha-history"`, `window_start=start`, `window_end=end`.
   - No samples at all → raise `SystemExit` with a clear message, like the other loaders.
2. `async fetch_ha_history_payload(client, entity_ids, *, start, end, chunk=1h)`: loop over
   `[start, end)` in `chunk` steps, call `fetch_history(client, ids, start=…, end=…,
   minimal=True)`, and concatenate rows per entity in order. Drop exact duplicate rows
   at chunk boundaries (same entity, same timestamp, same state).
3. CLI in `main()`:
   - `--ha-history` (store_true) and `--end` (ISO-8601, default now UTC; error if given
     without `--ha-history`).
   - `--ha-history` together with `--jsonl` → exit 2 with a message.
   - With `--ha-history`: still resolve the topology DB for `entity_to_ct` and the version
     triple (existing code). Error if `entity_to_ct` is empty. Fetch
     `[end - minutes, end]` for `sorted({entity ids in entity_to_ct that contain a "."})`
     (real entity ids, not aligner aliases) via `HAClient.from_env()`, then
     `load_capture_ha_history`, then the existing replay/report path.
   - The `--db` samples path must behave exactly as before when `--ha-history` is absent.
4. Update the module docstring's usage block with one `--ha-history` example.

  correct `ct_id`, values and UTC timestamps; `received_at == state_timestamp`.

  returns canned rows. A 3 h window with a 1 h chunk → 3 calls with contiguous bounds, and

  the simulator house the way `tests/simulation/test_replay_capture.py` does (reuse its
  fixtures and helpers by import if practical; otherwise just assert that `replay()` returns
  a run without raising).

  (call `main()` with a patched `sys.argv`; expect return code 2 / `SystemExit`).
