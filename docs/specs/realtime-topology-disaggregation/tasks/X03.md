## Objective
`main.py` (3 380 lines) and `integration.py` (1 112 lines) are touched by almost every area. Split them by responsibility, each piece with one future owner, with no behaviour change. Add clock injection.

## Steps
1. Use mixins (`class EngineCore(RuntimeMixin, SnapshotMixin, …)`) so `self` state stays shared and no call site changes.
2. Delete the stale comment at `main.py:844-850`, which says `to_thread` raises `ProgrammingError`. That contradicts `storage/database.py:82-89` (`check_same_thread=False`).
3. Add `clock: Callable[[], datetime] = utcnow` to `EngineCore` and to `WattMosaicBackend`. Replace `utcnow()` calls in moved code with `self._clock()`. This is plumbing for P6 and X07 replay.
