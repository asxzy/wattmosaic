# K03 — Topology edge, version, mapping edge, configuration event, residual and unknown-profile contracts

**Wave:** 1 · **Depends on:** K00 · **Size:** M · **Decisions:** DEC-10, 11 · **Interfaces:** §4 (contracts part) · **Analysis:** `analysis/C-topology-residual.md` §1, C1–C3, C5

## Objective
Typed reader↔reader edges with the HB §4.2 vocabulary, independent topology and mapping versions, configuration events, per-reader residual points and Unknown Load Profiles.

## Owns
- `engine/wattmosaic_engine/contracts/topology.py`
- its generated schemas
- new `tests/unit/test_contracts_topology.py`

## Steps
1. Implement `interfaces.md` §4 contracts: `RelationType`, `EdgeLifecycle` v3 (a new enum; leave the legacy one alone), `EdgeEvidence`, `TopologyEdge`, `TopologyVersion`, `Observability`, `MappingEdge`, `MappingVersion`, `ConfigurationEvent`, `ReaderResidualPoint`, `UnknownLoadProfile`.
2. `EdgeEvidence` fields: `support:int`, `conflict:int`, `parent_only:int`, `independent_causes:int`, `last_support_at`, `last_conflict_at`. Add the derived property `conflict_ratio`.
3. Validators:
   - `RETIRED` requires `valid_until`;
   - an edge cannot connect an endpoint to itself;
   - `beta_basis` is set iff `beta` is set;
   - `UnknownLoadProfile.lifecycle` has no confirmed state;
   - `MappingEdge.subject_kind == "unknown_profile"` only with `observability ∈ {INFERRED, PARTIAL}`.
4. Reuse `ConfigurationChangeKind`, `ChangeDetection`, `ChangeStatus` from `legacy.py`.

## Tests
- Round-trip.
- Every validator.
- `RelationType` contains exactly CONTAINS, SHARED_LOAD, PAIRED_LEG, CORRELATED, SAME_CONDUCTOR.
- `Observability` contains exactly the seven HB §9.7 states.
