# H1 — HA integration v3: client, null semantics, status/identifiability, group sensors

**Wave:** 4 · **Depends on:** K04, D4 · **Size:** M · **Decisions:** DEC-25 · **Design:** §11 · **Analysis:** `analysis/E-…` C7, WP-E6, traps T7–T9; `analysis/A-…` T9, T13

## Objective
HA never shows 0 W for an unknown or non-identifiable value. Status, identifiability, bounds, group and versions reach HA, group estimates get their own sensors, and every existing unique id stays byte-identical.

## Owns
- `custom_components/wattmosaic/api_client.py`, `coordinator.py`, `entity_defs.py`, `entity_values.py`, `sensor.py`, `binary_sensor.py`, `util.py`, `entity_migration.py`, `diagnostics.py`, `strings.json`, `translations/*`
- `custom_components/wattmosaic/const.py`, **except** `CONTRACT_VERSION`, which only Z1 touches
- `tests/integration/test_ha_integration.py`, `tests/integration/test_entity_id_stability.py`, `tests/integration/test_ha_energy_availability.py`, `tests/integration/test_integration_static.py`

## Steps
1. The coordinator reads `/snapshot` v3 (D4). It feature-detects v3 vs v2 by payload shape only for the duration of the integration branch; Z1 removes v2 handling.
2. Device power state follows design §11: None unless MEASURED, or ESTIMATED and IDENTIFIABLE. Attributes: `status`, `identifiability`, `lower_w`, `upper_w`, `group_id`, `provisional`, `topology_version_id`, `mapping_version_id`, `model_version_id`.
3. New enum sensors `estimate_status` and `identifiability` on the provenance device. List every option, or HA logs invalid-state errors.
4. Group sensors: one synthetic HA device per stable `group_id`, with unique id `{entry_id}_group_{group_id}_power`. A group that disappears goes unavailable, not deleted, for 7 days.
5. Energy: integrate only non-null power. A None never resets `total_increasing`; keep the held-total logic (ADR-0020).
6. Keep the pure-module separation that lets tests run without `homeassistant` (`test_integration_static.py`). Keep the no-actuation invariant.

## Tests
- The 250 W scenario reaches HA: the group sensor reads 250; member power states are None with attributes `[0, 250]` and `NON_IDENTIFIABLE`.
- AT-17 HA side: a missing reader leads to an unknown state.
- `test_entity_id_stability.py`: every pre-existing unique id and entity id is unchanged.
- The energy total does not reset when power becomes None.
- Enum options cover every state.
- Static: no service-call API.
