# S18 — Migration v018: power models v2, model events, learning observations, legacy flag

**Wave:** 2 · **Depends on:** X05, K06, S13 · **Size:** M · **Decisions:** DEC-31 · **Analysis:** `analysis/F-…` C1–C3, §5 traps

## Objective
Append-only model versions keyed by subject (device or component) rather than `(device, model_type)`, a status-event log, and deterministic learning observations. Legacy learned models are kept read-only and flagged.

## Owns
- new `engine/wattmosaic_engine/storage/migrations/v018_power_models.py`
- `engine/wattmosaic_engine/storage/repositories/models.py`, `repositories/learning.py` (from X05)
- new `tests/unit/test_v018_power_models.py`

## Steps
1. DDL: `power_model_versions_v3` (PK `version_id`; unique `subject_kind, subject_id, number`), `power_model_events` (append-only), `learning_observations` (PK `observation_id`). All L4.
2. Legacy:
   - copy every `device_model_versions` row into `power_model_versions_v3` with `basis=LEGACY_ABSOLUTE`, `model_class` mapped from `model_type`, and `spec` = `{"kind": "legacy", "parameters": <old json>}`. Add a `LegacySpec` variant **only** in this repository's read path; it is not exported in contracts;
   - log a `power_model_events` row `superseded`, reason `legacy_absolute`.

   **No legacy model is active after migration** (DEC-31). Inference falls back to priors and evidence.
3. Repository (no `INSERT OR REPLACE` anywhere):
   - `append_version`, `append_event`;
   - `active_version(subject_id)`, derived from the event log: the last `activated` without a later `superseded`/`rolled_back`;
   - `versions(subject_id)`;
   - `put_observation` (idempotent by id);
   - `observations(subject_id, status, since)`;
   - `dirty_subjects()` (subjects with confirmed observations newer than their active version's evidence).

## Tests
- Legacy rows are copied and none is active.
- `active_version` derivation, including rollback semantics: a never-activated or `rejected` version is never returned (fixes DEF-07).
- Observation idempotency.
- Exactly one active version per subject across a class change.
