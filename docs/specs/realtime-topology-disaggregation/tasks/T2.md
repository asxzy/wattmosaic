# T2 — Observation operator H(T, M, t) with physics-justified β and time-scoped factors

**Wave:** 3 · **Depends on:** T1, K08 · **Size:** L · **Decisions:** DEC-12, DEF-06 · **Design:** §5 (operator) · **Interfaces:** §4 runtime · **Analysis:** `analysis/C-…` §1 rows for §3.1/§3.3, C7, WP-C3; `analysis/D-…` §8.3

## Objective
One function builds H for any (topology version, mapping version, time). The output carries:
- per-entry observability class and edge lifecycle;
- residualised parent rows;
- scope-located unknown columns that enter every ancestor row;
- a conservative σ inflation for correlated nested rows;
- the calibration factor **valid at t** (this fixes DEF-06).

## Owns
- new `engine/wattmosaic_engine/electrical/operator.py`
- new `tests/unit/test_operator.py`
- `electrical/matrix.py` and `electrical/main_power.py` may be read and ported. They stay in place until Z2.

## Steps
1. `build_observation_operator(...)` per `interfaces.md` §4:
   - a subject's most specific reader comes from `MappingView`;
   - ancestors via CONFIRMED CONTAINS get `EXPECTED` with coefficient β;
   - PAIRED_LEG uses the leg coefficient;
   - SHARED_LOAD puts the subject in both rows;
   - a single-subject endpoint gets `DIRECT`.
2. β per design §5: unity, the recorded factor from `FactorRegistry` at `t`, or an estimated β labelled as such.
3. Residualised parent rows: subtract present children with their β. A **missing child** becomes an unknown column seeded with the child's last held value as a soft prior (DEC-12). The parent row is never dropped.
4. `unknown_scopes`: one column per reader scope, entering that reader's row and all its CONFIRMED ancestors.
5. `RowMeta.sigma_inflation = √k`, where k is the number of rows in the same CONTAINS chain that observe a common subject (consumed by I3, AT-9).
6. Cache by `(topology_version_id, mapping_version_id, factor_revision_set)`. The operator is rebuilt only when one of these changes (`analysis/B-…` trap 8).

## Tests
- AT-01/14 support: a Circuit-A device appears in the Circuit-A, Subpanel and Main rows with coefficient 1, and only once per row.
- A PROVISIONAL edge is not applied but is listed in `soft_alternatives`.
- A calibration change mid-window: samples before the change use the old factor (DEF-06).
- An estimated β is labelled and never absorbs residual.
- A missing child keeps the parent row with an extra unknown column.
- Replaying the same `(T, M, t)` gives a bit-identical operator.
- The cache hit rate on a stable version is 100 %.
