## Steps
1. `infer_group(...)` and `infer_steady(...)` with the signatures in `interfaces.md` §6. They are pure: no DB, no clock except the injected one, no globals.
2. `EstablishedStructure`: groups and identities from the last CONFIRMED event inferences. `infer_steady` adds only sum constraints for groups and point constraints for identities. A disagreement > 3σ goes into `unresolved_events` and is flagged CONFLICTED (DEC-22).
3. Determinism: the same inputs give a byte-identical `JointInferenceResult` (`result_id` equal).
