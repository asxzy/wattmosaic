# P1 — Canonical ingestion: ReaderMeasurement and HAEvent, polarity once, quarantine, candidate ring

**Wave:** 3 · **Depends on:** K02, S16, X03 · **Size:** M · **Decisions:** DEC-17, DEF-01 · **Design:** §2 · **Analysis:** `analysis/B-realtime-pipeline.md` §1, C7, C8, C10

## Objective
HASource emits normalized `ReaderMeasurement`s and device-free `HAEvent`s:
- endpoint revision applied once (polarity, multiplier, calibration version);
- HA context captured;
- invalid input quarantined;
- unlinked entities' events held in a bounded in-memory ring.

## Owns
- `engine/wattmosaic_engine/ingestion/ha_source.py`, `ingestion/normalize.py`
- new `engine/wattmosaic_engine/realtime/__init__.py`, `realtime/normalize.py` (normalizer + `compatible()` predicate), `realtime/candidate_ring.py`
- new `tests/unit/test_realtime_normalize.py`, `tests/unit/test_candidate_ring.py`

## Steps
1. **Write the DEF-01 test first.** It asserts that a declared `polarity=inverted` CT yields a negative `active_power_w` when the raw HA value is positive, end to end from a `state_changed` message to the `ReaderMeasurement`. Record whether it fails on the unmodified tree in the PR. If it fails, DEF-01 is confirmed: note it in `decisions.md` §8 through the orchestrator.
2. Normalizer: resolve `EndpointConfigRevision` at `observed_at` (S13 repository; `FakeVersionService`-style in-memory fake in tests). Then:
   - apply polarity, then the multiplier;
   - stamp `calibration_version`, `measurement_type`, `measurement_window_ms`, phase and leg;
   - flag and quarantine according to design §2;
   - count quarantined values per reader and reason (exposed for diagnostics).
3. Capture `context.id`, `context.parent_id` and `context.user_id` from the top level of the HA state object (they are dropped today: `ha_source.py:1042,1185`). Set `HAEvent.linked` from `ha_entity_links` at `observed_at`.
4. `_prime` replays get `PRIMED` and are delivered as seeds (`analysis/B-…` trap 9).
5. Candidate ring: 10 000 events or 30 min, whichever is smaller. API: `window(since, until)`, `by_context(id)`. Nothing is persisted from it (DEC-17); P5 decides persistence.
6. Keep emitting the legacy `Measurement`/`DeviceEvent` in parallel until P6 switches consumers. Z2 removes them.

## Tests
- Polarity (above).
- The multiplier revision applies only from its `valid_from`: a sample before it uses the old factor (DEF-06 at ingestion).
- Context captured.
- Out-of-range and non-finite values are quarantined, not delivered.
- An unknown phase stays `unknown` (never defaulted).
- Ring bound and eviction.
- `compatible()` truth table: power vs energy, phase mismatch, a paired leg, current without voltage.
