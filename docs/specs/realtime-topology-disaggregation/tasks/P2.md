# P2 — ReaderStateStore: one ring per reader, held/stale/missing, rolling baseline and noise

**Wave:** 3 · **Depends on:** P1 · **Size:** L · **Decisions:** DEC-18 · **Design:** §3 (store part) · **Analysis:** `analysis/B-…` C3, §5 traps 2–4

## Objective
Replace the four per-channel buffers that run on four clocks with **one** per-reader store keyed by `observed_at`. It has explicit zero-order-hold semantics, a long-run noise estimate, a baseline that does not absorb a step, late-arrival callbacks and restart persistence.

## Owns
- new `engine/wattmosaic_engine/realtime/reader_state.py`
- `engine/wattmosaic_engine/synchronization/aligner.py` (reduce it to the helpers the new store reuses: `robust_noise_mad`, `ChannelHealth`, cadence resolution. The power buffers are deleted in Z2; keep them working until then)
- new `tests/unit/test_reader_state.py`, `tests/unit/test_reader_state_perf.py`

## Steps
1. Implement design §3 "ReaderStateStore". The API is:
   - `add(m: ReaderMeasurement) -> AddResult(late: bool)`;
   - `held(reader, at) -> HeldReading` (K08);
   - `window(reader, since, until)`;
   - `sigma(reader)`, `baseline(reader)`;
   - `freeze_baseline(reader, until)`;
   - `on_late(callback)`;
   - `snapshot_state() -> bytes` and `restore_state(bytes)`.
2. σ_r uses 6 h of innovations that excludes samples inside open events, with floors as in the design.
3. Restart: the state blob is persisted every 10 min via a repository method. P2 adds `put_reader_state`/`get_reader_state` to `repositories/samples.py`; coordinate with the S16 owner if it is not yet `VERIFIED`.
4. All operations are O(1) amortized except `window`.

## Tests
- A held value is returned until `stale_after_s`; stale until `missing_after_s`; then `None` with state `missing` (AT-17 support).
- The baseline does not move more than 10 % of a 100 W step within 5 cadences after a step (frozen on suspect).
- σ at 15.7 s cadence with 20 min of history is within 25 % of the true σ.
- A late sample is inserted in order and the callback fires once.
- Restore after snapshot gives identical `held`, σ and baseline.
- Perf: 40 readers × 1 Hz for 1 h simulated, mean `add` < 0.2 ms (skip on CI if `CI_SLOW=1`).
