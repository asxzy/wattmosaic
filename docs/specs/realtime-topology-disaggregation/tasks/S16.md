# S16 — Migration v016: reader samples v2, event evidence, event groups, event inference records

**Wave:** 2 · **Depends on:** X05, K02, K04 · **Size:** M · **Decisions:** DEC-30 · **Analysis:** `analysis/A-…` C5, C11; `analysis/B-…` C3, C7

## Objective
Persist the full HB §2.1 measurement (today `measurement_basis` is dropped on insert, `database.py:541-565`), the immutable event evidence, the event groups (one row per revision) and the versioned interpretations.

## Owns
- new `engine/wattmosaic_engine/storage/migrations/v016_events.py`
- new `engine/wattmosaic_engine/storage/repositories/evidence.py`
- `engine/wattmosaic_engine/storage/repositories/samples.py` (from X05)
- new `tests/unit/test_v016_events.py`

## Steps
1. `ALTER ct_samples ADD` nullable columns: `current_rms_a`, `voltage_rms_v`, `reactive_power_var`, `power_factor`, `energy_wh`, `phase`, `leg`, `measurement_type`, `measurement_window_ms`, `calibration_version`, `quality_flags_json`, `measurement_basis`, `observed_at`. Use `add_column_if_missing`. `value_w` stays NOT NULL for now: energy-only readings are rare, and Z1 may rebuild.
2. New tables:
   - `event_evidence` (immutable; an `INSERT` that collides on id raises);
   - `event_groups` (PK `group_id, revision`);
   - `event_group_members`;
   - `event_inference_records` (revision chain);
   - `ha_events_v3` (device-free; replaces `device_events` for new writes).

   `TIERS`: all L2, with retention handled by D5.
3. Samples repository: `insert_readings(list[ReaderMeasurement])` persists every field.
4. Evidence repository:
   - `put_evidence` (refuses an update);
   - `put_group_revision`;
   - `latest_group(group_id)`;
   - `groups(since, status)`;
   - `put_record`;
   - `records_for_group`;
   - `records_for_subject(subject_id, since)`;
   - `history_rows_for_identifiability(subject_ids, since, limit)`, the query I4 needs.

## Tests
- `ReaderMeasurement` round-trips through `ct_samples` with every field.
- Re-inserting evidence raises.
- Group revisions are immutable, and a new revision is a new row.
- The record chain validator holds on read.
