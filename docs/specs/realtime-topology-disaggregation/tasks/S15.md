# S15 — Migration v015: mapping edges and versions, matrix cells and history

**Wave:** 2 · **Depends on:** X05, K03, K05, S13 · **Size:** M · **Decisions:** DEC-27, 30 · **Analysis:** `analysis/C-…` C3; `analysis/E-…` C6

## Objective
Separate subject↔reader mapping from topology (rule 20) and give the matrix a sparse current view plus an append-only history (HB §9.8–9.9).

## Owns
- new `engine/wattmosaic_engine/storage/migrations/v015_mapping.py`
- new `engine/wattmosaic_engine/storage/repositories/mapping.py`
- new `tests/unit/test_v015_mapping.py`

## Steps
1. DDL:
   - `mapping_edges`, `mapping_versions`;
   - `matrix_cells` (PK `row_kind, row_id, reader_id`; columns for every `MappingCell` block as JSON plus indexed scalar columns: `visual`, `mapping_status`, `observability`, `identifiability`, `updated_at`);
   - `matrix_cell_versions` (append-only, plus `mapping_version_id` and `valid_from/valid_until`).

   `TIERS` = L4.
2. Backfill `mapping_edges` (`declared_by=migration`) from three sources:
   - `DeviceTopology.branch_ct_ids` (`devices.branch_ct_ids_json`);
   - `DeviceConfiguration.monitored_by_ct_ids`;
   - `topology_relations` of kind `DEVICE_CT_ASSOCIATION` (keep `valid_to` where present; superseded rows become RETIRED).

   Observability: a user declaration becomes `INFERRED` with lifecycle `CONFIRMED`; an auto placement becomes `INFERRED`/`PROVISIONAL`; an association becomes `INFERRED` with its verdict-mapped lifecycle. Create `map-1`.
3. No cells are backfilled; M2 materialises them on first run.
4. Repository:
   - `mapping_edges(version_id, subject_id=None, endpoint_id=None)`;
   - `bulk_cells(filters)`, a `_reader()` connection with no writer lock (fixes `analysis/E-…` T6);
   - `upsert_cells(delta)` (single transaction: current upsert plus version append);
   - `cell_history(row, reader, since)`;
   - `cells_as_of(t)`.

## Tests
- Backfill from the three sources is deduplicated by (subject, endpoint).
- `upsert_cells` appends exactly one history row per changed cell.
- `cells_as_of` returns the old value.
- `bulk_cells` does not take the writer lock (patch the lock to raise).
