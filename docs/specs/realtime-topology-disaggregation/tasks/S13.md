# S13 — Migration v013: endpoints, devices, components, HA entities and links

**Wave:** 2 · **Depends on:** X05, K01 · **Size:** L · **Decisions:** DEC-02, 04, 08 · **Interfaces:** §10 · **Analysis:** `analysis/A-…` C1–C4, WP-A2, §5 T1–T5, T9

## Objective
Create the canonical entity tables and **backfill them losslessly** from today's tables. Every existing id survives: `ct_id` becomes `endpoint_id`, and `device_id` becomes the Physical Device `device_id`.

## Owns
- new `engine/wattmosaic_engine/storage/migrations/v013_entities.py`
- new `engine/wattmosaic_engine/storage/repositories/entities.py`
- new `tests/unit/test_v013_entities.py`

## Steps
1. DDL for `measurement_endpoints`, `endpoint_config_revisions`, `physical_devices`, `load_components`, `ha_entities`, `ha_entity_links` (`interfaces.md` §10). Declare `TIERS` (all L4).
2. Backfill inside the same `apply` callable:
   - `ct_channels` → endpoint (`kind=CT`, `scope=CIRCUIT`, or `PANEL_FEED` for mains) plus revision 1. Phase, polarity and multiplier come from the channel; the time-scoped multiplier history comes from `ct_measurement_factors` (one revision per factor interval).
   - `devices` + `device_configurations.payload_json` → `physical_devices` (`origin=migration`). Use the ids verbatim. Rows whose id matches the per-CT auto pattern (`dev_<ct>`, `_is_ct_auto_circuit` heuristics in `disaggregation/mapping.py:231-266`) get `origin=migration` and a metadata flag `legacy_ct_device=1`. D2 decides whether to retire them; never delete here.
   - `ha_entity_bindings`, `DeviceTopology.metadata` keys (`state_entity_ids`, `link_state_entity_ids`, `config_load_entity_ids`) and `DeviceConfiguration.state_entity_ids/mode_entity_ids/controllable_entity_ids` → `ha_entities` + `ha_entity_links` (`declared_by=migration`), deduplicated.
3. Repository: CRUD plus `endpoint_revision_at(endpoint_id, t)`, `links_for_entity(entity_id, at)` and `subjects_for_ha_device(ha_device_id)`. Bulk reads use `_reader()`.
4. Do **not** drop or alter legacy tables (DEC-02; Z1 renames them).

## Tests
- Build schema-11 DBs with the X05 fixture builder, seeded with:
  - nested CTs with factors;
  - a `dev_<ct>` auto device;
  - a user device with three entity links in three different stores;
  - a device whose JSON contains the retired role.

  Assert:
  - counts preserved;
  - ids identical;
  - links deduplicated;
  - `endpoint_revision_at` returns the right multiplier per interval.
- Idempotent (apply callback run twice is a no-op).
- Failure injected mid-apply leaves `user_version == 11` and no new tables.
- The backup file exists.

## Traps
- `extra="forbid"`: legacy JSON payloads must be read through tolerant dict access, not by validating legacy models.
- `foreign_keys=ON`: insert in dependency order.
