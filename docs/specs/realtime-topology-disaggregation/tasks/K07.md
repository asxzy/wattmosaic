# K07 — Acceptance harness: the 20 HB §21 tests as xfail-strict

**Wave:** 1 · **Depends on:** K01–K06, K08, X07 · **Size:** M · **See:** `../traceability.md` §1

## Objective
Write all 20 mandatory acceptance tests **now**, against the target public surfaces, marked `@pytest.mark.xfail(strict=True, reason="closed by <TASK>")`. Each closing task removes exactly its marker. Strictness means an accidental pass fails CI and forces the marker's removal, so progress is always visible.

## Owns
- new `tests/acceptance/__init__.py`, `tests/acceptance/conftest.py`
- new `tests/acceptance/test_at01_nested_no_double_count.py` … `test_at20_ui_explains_estimates.py` (20 files; slugs as in traceability §1)
- new `tests/acceptance/README.md`, which lists the closing task per file

## Steps
1. `conftest.py` fixtures:
   - `hb17` (X07 house, seed 17);
   - `engine_harness`: a factory that starts `EngineCore` with an injected clock and the X07 replay driver. Until P6 lands it can raise `NotImplementedError`, which is fine under xfail;
   - `api_client` (aiohttp test client on the v3 routes);
   - `panel_model` (U1's `matrix-model.js` through `tests/unit/panel_harness.py`).
2. Each test asserts the **semantics** in traceability §1, never only status codes. Assertions use the K0x contract types: for example, AT-07 asserts on `DeviceGroupEstimate` and on `DeviceEstimate.point_w is None`.
3. AT-07 must include the three variants and the mutation guards defined in `I4.md` §Tests. It may import I4's helper fixtures once they exist; until then it builds the scenario from X07.
4. Register a `pytest` marker `acceptance`. CI picks it up through the normal `pytest -q`.
