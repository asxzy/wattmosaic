# X07 — Simulator extensions, HB §17 reference house, replay driver skeleton

**Wave:** 0 · **Depends on:** — · **Size:** M · **Analysis:** `analysis/B-realtime-pipeline.md` §4 WP-B8; HB §17

## Objective
Give every later task a deterministic way to produce the conditions the handbook requires. That includes the **HB §17 reference house**, which K07's acceptance tests run against.

## Owns
- `tools/simulator/*`
- `tests/simulation/test_simulator*.py` (extend)
- new `tools/simulator/hb17.py`, `tools/simulator/replay.py`
- new `tests/simulation/test_hb17_house.py`

## Steps
1. Simulator features:
   - HA `context` (`id`, `parent_id`, `user_id`) on state changes, including automation bursts sharing a parent context and a *decoy* context whose physical changes are 60 s apart;
   - push-on-change silence (no sample when the value is unchanged), plus `last_reported`;
   - a per-reader `measurement_window_ms` with window-averaged values (a step smeared across one window);
   - late backfill beyond the group window;
   - out-of-order delivery;
   - per-reader clock skew;
   - an inverted CT with declared polarity;
   - a smart-plug endpoint measuring one device;
   - a non-HA periodic load (fridge compressor);
   - delayed and transient responses (HVAC compressor +90 s after the thermostat; blind transient, then standby);
   - two always-co-switched lights, with a variant that adds 3 solo switches of one light.
2. `hb17.build(seed, minutes, variant)` builds the reference house:
   - topology: Main 1 500 W ⊃ Subpanel 800 W ⊃ {Circuit A 300 W, Circuit B 200 W}; Main ⊃ Circuit C 400 W; unmonitored load on Main;
   - devices: TV on a plug with 3 W standby on Circuit A, a fridge without HA on Circuit B, two living-room lights on Circuit A;
   - scripted steps 3–10 of HB §17, including the plug move (step 9) at a configurable minute.

   It returns HA-shaped message streams and ground truth under separate keys; extend the `frames.py` leak detector to the new truth keys (`true_onset_at`, `true_circuit`).
3. `replay.py`: a driver that feeds HA-shaped messages to any object with `on_state_changed(msg)` while advancing an injected clock. P6 binds it to `EngineCore`; here it is tested with a recording stub.

## Tests
- `test_hb17_house.py`:
  - same seed gives byte-identical streams;
  - the leak detector passes;
  - each HB §17 step occurs at its scripted time;
  - the plug move changes the circuit in truth only.
- Extend `test_simulator.py` for context ids, push-on-change, window averaging and late delivery.
