# K08 — Runtime interface types and fakes

**Wave:** 1 · **Depends on:** K00 (and the K02–K06 *shapes*, which can be stubbed by name) · **Size:** M · **Interfaces:** §4 runtime, §5 registry, §6 runtime, §7, §8 updater

## Objective
Fix every cross-area runtime handoff as frozen dataclasses or Protocols, with **deterministic fakes**. Wave 3 tasks then build and test against fakes in parallel, without waiting for each other.

## Owns
- new `engine/wattmosaic_engine/runtime/__init__.py`, `runtime/interfaces.py`, `runtime/fakes.py`
- new `tests/unit/test_runtime_fakes.py`

## Steps
1. `interfaces.py`:
   - `EntryMeta`, `RowMeta`, `AlternativeEdge`, `ObservationOperator`;
   - `TopologyView` and `MappingView` Protocols (edges by lifecycle; `subjects_on(reader)`; `ancestors(reader, lifecycles)`; `most_specific_reader(subject)`);
   - `UnknownPrior`, `ResidualModelView`;
   - `PredictionContext`, `ModelSetView`;
   - `JointSolution`;
   - `IdentifiabilityHistory` (`events_touching(subject_ids, since) -> list[HistoryRow]`), `MatchStore` (read snapshot plus `apply(delta) -> MatchStore`), `EstablishedStructure` (groups, identities);
   - `HeldReading` (value, `held_since`, `last_confirmed_at`, state `held | stale | missing`);
   - `VersionService`, `MatrixUpdater`;
   - the signatures of `infer_group` and `infer_steady` as `Protocol` callables;
   - `Clock = Callable[[], datetime]`.

   Everything follows `interfaces.md`.
2. `fakes.py`:
   - `FakeTopology.from_tree(spec)` builds the HB §17 house tree in one call;
   - `FakeMapping`;
   - `fake_operator(...)`, a correct but naive H for CONFIRMED CONTAINS chains with coefficient 1;
   - `FakeModelSet` (fixed ΔP priors, optional kernels);
   - `FakeResidual` (constant UnknownPrior);
   - `InMemoryHistory`, `InMemoryMatchStore`, `FakeVersionService` (in-memory append-only);
   - `RecordingMatrixUpdater`.
3. Fakes must be small and obviously correct. They are test doubles, not reference implementations, and must never be imported by production code. A static test enforces this.

## Tests
- Each fake satisfies its Protocol (`isinstance` with `runtime_checkable`).
- `fake_operator` on the HB §17 tree puts a Circuit-A device in the rows of Circuit A, Subpanel and Main, with coefficient 1.
- A static test: no module under `engine/wattmosaic_engine/` except `runtime/fakes.py` imports `runtime.fakes`.
