# T1 — Typed topology graph built from edges filtered by lifecycle

**Wave:** 3 · **Depends on:** K03, S14, K08 · **Size:** L · **Decisions:** DEC-10, 11 · **Design:** §5 · **Analysis:** `analysis/C-topology-residual.md` C1, C2, WP-C1

## Objective
Edges become the authority. CONFIRMED CONTAINS is hard structure. PROVISIONAL edges are listed as soft alternatives. CANDIDATE and CORRELATED edges never shape the hierarchy. Today any declared `parent_ct_id` is used unconditionally (`electrical/topology.py:101-173`).

## Steps
1. `TopologyGraph.from_edges(edges, endpoints, at)`:
   - `parent(reader, lifecycles={CONFIRMED})`, `ancestors`, `children`;
   - `paired_leg(reader)` (port `double_pole_leg` / `complete_leg_pair` / `leg_coefficient` semantics, `topology.py:349-393`);
   - `same_conductor_group(reader)` (alias as fallback, never a row, `matrix.py:296-317`);
   - `soft_alternatives()`;
   - `primary_display_tree()`, the input to M1's columns.
2. Validation (port from `hierarchy.py:930-1050`): no cycles, no self-edges, at most one CONFIRMED CONTAINS parent per reader. A contradiction moves the weaker edge to CONFLICTED with a reason.
3. Pinned or rejected user edges override inference edges for the same pair.
