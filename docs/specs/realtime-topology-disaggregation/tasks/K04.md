# K04 — Inference contracts: candidates, matches, estimates, groups, records, snapshot

**Wave:** 1 · **Depends on:** K00 · **Size:** M · **Decisions:** DEC-19, 22, 24, 26 · **Interfaces:** §6 (contracts part) · **Analysis:** `analysis/D-matching-joint-inference.md` C1–C6, C12

## Objective
First-class device estimates with nullable values, first-class group estimates, match states, versioned event inference records, and the HB §12.1 `InferenceSnapshot` with a `ReconciliationV3` whose terms are all nullable.

## Owns
- `engine/wattmosaic_engine/contracts/inference.py`
- its generated schemas
- new `tests/unit/test_contracts_inference.py`

## Steps
1. Implement `interfaces.md` §6 contracts: `MatchState`, `CandidateSource`, `CandidateHypothesis`, `DeviceEstimate`, `DeviceGroupEstimate`, `UnknownEstimate`, `JointInferenceResult`, `EventInferenceRecord`, `ReconciliationV3`, `InferenceSnapshot`.
2. `ReconciliationV3` fields are all `float | None`:
   - `main_w`
   - `identified_w` (Σ MEASURED/ESTIMATED, each subject once)
   - `group_w` (Σ group sums)
   - `unknown_w`
   - `residual_w`
   - `export_w`
   - `meter_spread_w`

   Add a property `balance_error_w` that is None if any term is None.
3. Validators. These are mandatory and are the contract half of HB §8.4:
   - `status == ALLOCATED` ⇒ `allocation_rule` is set; otherwise `allocation_rule is None`;
   - `status == MEASURED` ⇒ `method == DIRECT_READING` and `source_reader_ids` has length 1;
   - `identifiability ∈ {NON_IDENTIFIABLE, INSUFFICIENT_EVIDENCE}` ⇒ `point_w is None`;
   - `point_w is None` ⇒ `status ∈ {UNKNOWN}`, except group members, which are also UNKNOWN;
   - `group_id` set and identifiability `NON_IDENTIFIABLE` ⇒ `point_w is None`;
   - `DeviceGroupEstimate.point_w` set ⇒ `identifiability == GROUP_IDENTIFIABLE`, and its bounds contain `point_w`;
   - `EventInferenceRecord`: `interpretation_revision == 1` ⇔ `previous_record_id is None` (reuse the pattern of `InferenceRecord`, `legacy.py` ~`:1292-1408`).
4. `JointInferenceResult.result_id` = content hash of (group id, revision, versions, sorted estimates). This keeps it replay-deterministic.

## Tests
- Every validator, with a positive and a negative case.
- **Mutation case:** constructing a member estimate with `point_w=125.0` and `NON_IDENTIFIABLE` raises.
- Snapshot round-trip with None values preserved.
