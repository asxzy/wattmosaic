# X04 — Split `api/server.py` into route modules and `facade.py` into protocols (no behaviour change)

**Wave:** 0 · **Depends on:** — · **Size:** M · **Analysis:** `analysis/E-mapping-matrix-ui-ha.md` §4 E3

## Objective
Each area will own its routes. Move handlers out of `create_app` so later tasks add or remove routes in their own files without touching `server.py`.

## Owns
- `engine/wattmosaic_engine/api/server.py`, which keeps the app factory, middleware, auth, error mapping and the call to `routes.register_all(router, base, deps)`
- new `engine/wattmosaic_engine/api/routes/{__init__,health,snapshot,devices,topology,mapping,discovery,models,commands,export,metrics,diagnostics}.py`. Each exposes `register(router, base, deps)`
- `engine/wattmosaic_engine/api/facade.py` and new `api/protocols.py`: one Protocol per area (`SnapshotProvider`, `TopologyProvider`, `MappingProvider`, `ModelsProvider`, `DiscoveryProvider`, `DiagnosticsProvider`), composed into `EngineFacade`
- new `tests/unit/test_routes_discovery.py`

## Steps
1. `routes/__init__.register_all` discovers modules with `pkgutil.iter_modules`, sorted, and calls each `register`. Later tasks add new modules without editing it.
2. Keep paths, auth, timeouts (`api/timeouts.py`), status codes and response shapes identical.

## Tests
- Full suite green, especially `tests/unit/test_api.py`, `tests/integration/test_engine_api_contract.py`, `tests/unit/test_gateway_proxy.py`.
- `test_routes_discovery.py`: the set of registered `(method, path)` equals a snapshot list captured before the split.
