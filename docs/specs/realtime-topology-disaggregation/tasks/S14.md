# S14 — Migration v014: topology edges, versions, configuration events

**Wave:** 2 · **Depends on:** X05, K03, S13 · **Size:** M · **Decisions:** DEC-10, 11 · **Analysis:** `analysis/C-topology-residual.md` C1, C2, C4, §5 T2

## Objective
Persist typed edges **with lifecycle**: today the `topology_relations` table drops it (`migrations.py:647-662`). Also persist versions with a parent chain and configuration events. Backfill from the pointer fields and from the existing relations.

## Owns
- new `engine/wattmosaic_engine/storage/migrations/v014_topology.py`
- new `engine/wattmosaic_engine/storage/repositories/topology_v3.py`
- new `tests/unit/test_v014_topology.py`

## Steps
1. DDL: `topology_edges` (all `TopologyEdge` fields; `evidence_json`), `topology_versions_v3`, `configuration_events`. `TIERS` = L4.
2. Backfill:
   - `ct_channels.parent_ct_id` → `CONTAINS` (`declared_by=migration`). The lifecycle is `CONFIRMED` if the channel's `topology_status` was user-confirmed, otherwise `PROVISIONAL`;
   - `paired_ct_id` → `PAIRED_LEG` (one edge per unordered pair);
   - `alias_of_ct_id` → `SAME_CONDUCTOR`;
   - `topology_relations` of kind `ELECTRICAL_PARENT_CHILD` → `CONTAINS` with its recorded status mapped;
   - `CT_MEASUREMENT_OVERLAP` → `CORRELATED` (never containment: HB §4.2).

   `DEVICE_CT_ASSOCIATION` and `CIRCUIT_MEMBERSHIP` are **not** topology; S15 takes them.
3. Version: create `topo-<n>`, where n = max(legacy `topology_versions.version`) + 1. Its `parent_version_id` is None, and it carries `legacy_snapshot_version` metadata pointing to the latest legacy snapshot row.
4. Repository: `edges(version_id, lifecycles=None)`, `edge_history(edge_id)`, `insert_version`, `set_active`, `append_configuration_event`, `events(status=None)`.

## Tests
- Pointer fixtures (nested, paired, alias, overlap) produce exactly the expected edge set with the expected lifecycles.
- Lifecycle survives a reopen (the current bug).
- Idempotency, rollback-on-failure, counts.
