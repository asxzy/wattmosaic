# T5 — Topology inference engine: asymmetric delta and absolute evidence ledger

**Wave:** 4 · **Depends on:** T1, T3, T4, P4 · **Size:** L · **Decisions:** DEC-10 · **Design:** §5 (ledger) · **Analysis:** `analysis/C-…` §1 row §4.3, WP-C4, traps T1, T8, T9, T10, T13 · **Closes:** AT-02

## Objective
One topology inference engine that replaces `nesting.py` (live wizard) and `hierarchy.py` (audit pass). It accumulates per-pair evidence from **signed reader deltas**:
- child→parent agreement supports an edge;
- a child moving without the parent counts against it;
- a parent moving alone is neutral residual evidence.

Absolute containment is kept as a gate. Edge lifecycle is driven per DEC-10.

## Steps
1. Input: FINAL `EventEvidence` per reader (P4) grouped by event group (P5), plus aligned absolute series for the gates.
2. Ledger per ordered pair, persisted in `TopologyEdge.evidence` (S14):
   - update incrementally per FINAL group;
   - never recompute from a window (perf, `analysis/C-…` T13).
3. Lifecycle transitions follow design §5 exactly. Propose a new topology version via `VersionService.propose_topology` and promote it when an edge crosses into CONFIRMED or CONFLICTED. Never touch user-pinned or REJECTED pairs.
4. Emit CORRELATED for repeatable co-response without containment, and SAME_CONDUCTOR from the duplicate detector (`nesting.py:309-351`).
5. Keep the guards:
   - ≥ 2 independent causes (`hierarchy.py:131-140`);
   - scaled-copy refusal;
   - basis-unknown refusal;
   - containment ≥ 0.995 (do not lower it, `analysis/C-…` T8);
   - leg nodes by suffix, with a phase gate that does not trust declared phase blindly (T9).
