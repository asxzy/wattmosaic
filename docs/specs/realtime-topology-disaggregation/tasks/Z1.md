# Z1 — Contract 3.0.0: remove legacy contracts, fields and routes; bump and mirror; schemas

**Wave:** 5 · **Depends on:** Z2 · **Size:** M · **Decisions:** DEC-01, 02, 11, 28 · **Analysis:** `analysis/A-…` C9, §5 T6, T7

## Objective
Cut over to contract `3.0.0`:
- delete the legacy contract models and enums;
- delete the replaced HTTP routes;
- move `CONTRACT_VERSION` to `foundation.py` and set it to `3.0.0` in both the engine and the integration mirror;
- regenerate every schema;
- rename the legacy tables to `*_legacy`, read-only (migration 25).

## Owns
- `engine/wattmosaic_engine/contracts/legacy.py` (delete or shrink to nothing), `contracts/foundation.py` (`CONTRACT_VERSION`), `contracts/__init__.py` (remove the legacy import: the one sanctioned edit of the facade)
- `custom_components/wattmosaic/const.py` (`CONTRACT_VERSION` line only) and `api_client.py` (drop v2 shape handling)
- `data/schemas/*` (regenerate; delete the legacy schema files), `tools/dev/export_schemas.py` (drop the legacy `MODELS` list)
- `engine/wattmosaic_engine/api/routes/{mapping,topology,snapshot,devices,…}.py` legacy handlers (delete), plus `api/protocols.py` legacy methods

1. Delete the legacy models listed in `architecture.md` §5. A test that still imports one either moves to v3 or is deleted (with a note in the PR).
2. Set `CONTRACT_VERSION = "3.0.0"` and the mirror. The integration's `_check_contract` refuses a major mismatch by design (`api_client.py:190-210`). Engine and integration must ship together (DEC-01).
3. Delete the routes `/mapping`, `PUT /topology`, `/topology/confirm`, `/topology/nesting`, `/relations`, `/confidence_tiers`. Any v2 snapshot shape is gone.
4. Migration v025: `ALTER TABLE x RENAME TO x_legacy` for the tables listed in `interfaces.md` §10 notes (`ct_channels`, `devices`, `topology_versions`, `topology_relations`, `device_model_versions`, `device_models`, `residual_power`, `device_events`, `ha_entity_bindings`). Add read-only triggers (`BEFORE INSERT/UPDATE/DELETE … RAISE(ABORT)`). No drops (DEC-02).
5. Extend `test_no_legacy_paths.py` (Z2) with the contract symbols listed in `architecture.md` §5.
