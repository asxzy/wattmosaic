# M1 — Matrix projection core: cells, column tree, row tree, special rows

**Wave:** 3 · **Depends on:** K05, K08 · **Size:** L · **Decisions:** DEC-27 · **Design:** §8 · **Analysis:** `analysis/E-mapping-matrix-ui-ha.md` §1, C1–C5, WP-E1 · **Closes:** AT-01, AT-13

## Objective
A pure, deterministic `materialise_cells` that turns operator + estimates + mapping + history into v3 cells. It produces:
- an L0–L4 column tree with annotations;
- a row tree with device, component, group, unknown-profile, reader-residual and summary rows;
- EXPECTED observability propagated to ancestor readers (missing today);
- the deterministic visual category.

## Steps
1. `build_columns(topology_view, endpoints) -> list[ColumnNode]` from T1's `primary_display_tree`. Levels: L0 domain, L1 panel/source, L2 subpanel, L3 circuit, L4 reader. Annotations for SHARED_LOAD, PAIRED_LEG, SAME_CONDUCTOR, CORRELATED and PROVISIONAL CONTAINS. Each endpoint is one leaf.
2. `build_rows(devices, components, groups, profiles, readers, areas) -> list[RowNode]` per DEC-27. HA registry devices that are not linked to a Physical Device are **not** rows. Area is used only for grouping.
3. `materialise_cells(operator, result_or_snapshot, mapping_view, match_view, history) -> list[MappingCell]`. Sparse per design §8. Identifiability is its own field and never part of the mapping status. Contributions come from current estimates, never from a model's total as a stand-in (`mapping.py:430-436` today).
4. `physical_total` counts each subject once (from estimates and group sums) plus the main residual. `reader_totals` are per column and never summed.
5. Port the honesty helpers from `disaggregation/mapping.py`: None-not-0, `stable_json`, the bounds bracket. Do not port `_is_ct_auto_circuit` (`analysis/E-…` T12).
