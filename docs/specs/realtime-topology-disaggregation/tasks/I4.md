## Step 0 — write the mandatory 250 W test FIRST
The previous attempt was reverted, and its stash kept no failing test (`analysis/D-…` §0.4, trap 13). Write `test_group_250w.py` before any solver code. It must fail on the unmodified engine via the legacy `DisaggregationEngine.infer` path. Use an adapter fixture that runs either the legacy engine or `infer_group`, so the test proves the old defect.

**Setup:**
- Main ⊃ Subpanel ⊃ Circuit A. Light 1 and Light 2 are on Circuit A only.
- 12 historical groups where both switch within 1 s.
- Now both go OFF→ON. Circuit A, Subpanel and Main each read +250 W (±2 W).

**Variants:**
- B: models declare 125 W each.
- C: a steady-state snapshot one cycle later, with no transition.

**Assertions (A, B, C identical for members):**
- Exactly one `DeviceGroupEstimate` with members {L1, L2}, point 250 ± noise, `GROUP_IDENTIFIABLE`, source readers [Circuit A, Subpanel, Main], and evidence refs naming the group and readers.
- Each member: `point_w is None`, `NON_IDENTIFIABLE`, bounds [0, 250] ± noise with `basis="non_negativity"`. No 125 W anywhere. The status is never ESTIMATED or ALLOCATED.
- ΔU ≈ 0. The residual does not contain the 250 W. Total attributed is 250, not 750.

**Mutation guards** (each must make the test fail):
- the solver patched to return the equal split;
- estimate assembly patched to fill members from models;
- bounds collapsed to [250, 250].

**Positive control:** add 3 historical groups where L1 switched alone at 100 W. The result is IDENTIFIABLE, with L1 ≈ 100 and L2 ≈ 150 as ESTIMATED with finite bounds.

## Steps
1. `IdentifiabilityAnalyzer.analyze(operator, solution, candidates, history: IdentifiabilityHistory) -> IdentifiabilityReport`. Build the experiment matrix per design §7, then compute rank, singular values, condition number, column correlation, null-space share and group-functional checks. Classify every subject and group into the five states.
2. `group_id = sha256(sorted(member_ids))[:16]`, stable across cycles.
3. `bounds.py`: a small LP per member (`scipy.optimize.linprog`). Constraints are the identified sums ± 3σ, sign classes and declared ceilings. **Never** model priors (DEC-19). A zero-width result is only allowed for IDENTIFIABLE.
4. Reuse `analyse_identifiability` (`electrical/solver.py:136-256`) and `group_fit._co_toggle_groups` (`disaggregation/group_fit.py:504-553`) by import; do not edit those files.
