# U1 — Matrix UI (user-facing), built against K05 fixtures

**Wave:** 3 · **Depends on:** X06, K05 · **Size:** L · **Decisions:** DEC-29, DEF-08 · **Design:** §8 · **Analysis:** `analysis/E-…` §1 UI rows, WP-E4 · **Closes:** AT-12

## Objective
The matrix becomes a major user-facing view (HB §19):
- nested `colSpan` headers L0–L4 from `columns`;
- one leaf per reader, with annotation chips;
- a frozen identity column;
- a row tree with distinct special rows;
- eight visual categories that never rely on colour alone;
- cell, column and row drill-downs;
- structured filters;
- a compact default with a "Diagnostic" toggle.

## Owns
- `addon/ui/view-matrix.js`, `addon/ui/matrix-model.js`, `addon/ui/matrix-cell.js`, `addon/ui/matrix-drill.js`, `addon/ui/matrix.css` (all from X06)
- new `tests/unit/test_panel_matrix.py`
- `tests/unit/test_panel_matrix_e2e.py`
- `tests/acceptance/test_at12_multilevel_columns.py` (remove xfail)

## Steps
1. `matrix-model.js` is pure and node-testable:
   - `headerRows(columns)` → rows with `colSpan` (Σ colSpan per row = leaf count);
   - `rowTree(rows)`;
   - `cellView(cell)` → {category, text label, glyph, value or interval text, confidence glyph, age};
   - `applyFilters(payload, filters)`.
2. `view-matrix.js`:
   - render from `GET /matrix`, using the K05 fixture `tests/fixtures/matrix/hb17_payload.json` until M3 lands;
   - poll `/status.mapping_version_id` and refetch only on change;
   - sticky headers and a frozen first column. Fix `app.css:1011` (DEF-08): body-row `th` must not have `top`.
3. Drill drawers call M3's cell, reader and row routes and show:
   - mapping history;
   - event groups;
   - evidence refs;
   - confidence components;
   - reasons for uncertainty;
   - contradictions.
4. Group rows show the group value. Member cells show "—" plus the interval and a "non-identifiable" text label. A residual row is labelled "Unexplained at <reader>", and an unknown-profile row "Unknown load <id>".
5. Diagnostic toggle: keep the current debug trace, raw-id toggle, source ledger and identifiability cards behind it.

## Tests
- **AT-12 (DOM):** the header row count equals the tree depth; Σ colSpan per header row = leaf count = reader count.
- Every category has distinct text (not colour-only).
- Group and member rendering.
- Filters.
- Polling refetches only on a version change.
- Playwright (skip-if-absent): scrolling keeps the identity column and headers visible.
- 500×100 fixture: render < 1.5 s and DOM nodes < 60 000 (groups collapsed by default).
