# S17 — Migration v017: nullable inference results, snapshots, group estimates, legacy flags

**Wave:** 2 · **Depends on:** X05, K04 · **Size:** M · **Decisions:** DEC-26 · **Analysis:** `analysis/A-…` C6, C7; `analysis/D-…` C1–C3

## Objective
Make "unknown" storable as NULL, persist every estimate field (status, bounds, group, versions), and add sparse snapshot persistence. Today `inference_results.power_w` is NOT NULL and `power_state`, bounds and group fields are lost on the DB round-trip.

## Owns
- new `engine/wattmosaic_engine/storage/migrations/v017_results.py`
- `engine/wattmosaic_engine/storage/repositories/inference.py` (from X05)
- new `tests/unit/test_v017_results.py`

## Steps
1. Rebuild `inference_results` (create-copy-rename in the same transaction; SQLite cannot drop NOT NULL). Changes:
   - `power_w` becomes NULL-able;
   - add `status`, `identifiability`, `lower_w`, `upper_w`, `bounds_basis`, `group_id`, `method`, `level`, `topology_version_id`, `mapping_version_id`, `model_set_id`, `provisional`, `legacy_semantics`.
2. Data rules (DEC-26):
   - rows whose `provenance_json` has `power_w_is_placeholder=true` get `power_w = NULL` and `legacy_semantics='placeholder_zero'`;
   - rows with `source='direct_measured'` get `legacy_semantics='legacy_direct'`;
   - other legacy rows get `legacy_semantics='legacy_v2'`.

   Never reinterpret an old number as validated.
3. `reconciliation_results` gets the same treatment: nullable terms, plus `group_w`.
4. New tables: `inference_snapshots` (L2; written only when content changes: store a content hash and skip duplicates) and `device_group_estimates` (L1).
5. Repository: `put_estimates(result: JointInferenceResult)`, `latest_estimates()`, `put_snapshot(snapshot)` (no-op if the hash is unchanged), `latest_snapshot()`, `group_history(group_id, since)`.

## Tests
- Placeholder rows become NULL plus the flag.
- A non-placeholder legacy value is unchanged but flagged.
- A NULL round-trips as None.
- A duplicate snapshot is not written twice.
- Column order and indexes survive the rebuild (`PRAGMA index_list`).
