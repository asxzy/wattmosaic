# X06 — Panel as ES modules, plus gateway, check_panel and test-harness port (no behaviour change)

**Wave:** 0 · **Depends on:** — · **Size:** M · **Analysis:** `analysis/E-mapping-matrix-ui-ha.md` §4 E0, §5 T1–T5

## Objective
Split `addon/ui/app.js` (5 490 lines) into flat native ES modules so U1 and U2 can own views separately. The panel must look and behave identically under HA ingress.

## Owns
- `addon/ui/index.html`
- `addon/ui/app.js` → `addon/ui/{main,core,view-overview,view-devices,view-topology,view-discover,view-quality,view-diagnostics,view-matrix,matrix-model,matrix-cell,matrix-drill}.js`
- `addon/ui/app.css` (split off `matrix.css`)
- `addon/gateway.py` (`UI_ASSETS`, `ASSET_TYPES` and the static handler only)
- `tools/dev/check_panel.py`
- `scripts/package_addon.sh` (`:115`)
- `scripts/validate_addon.sh` (`:85-88`, `:461-474`)
- `tests/unit/test_panel.py`, `tests/unit/test_panel_data.py`, `tests/unit/test_panel_matrix_e2e.py`
- `tests/integration/test_release_pipeline.py` (`:126`)
- new `tests/unit/panel_harness.py`

## Steps
1. `<script type="module" src="ui/main.js">`. Relative imports only; never absolute `/ui/…` (ingress prefix). The 401-reload-once logic (ADR-0032, `app.js:44-86`) lives only in `core.js`.
2. Gateway: replace the fixed allowlist with `^[a-z0-9-]+\.(js|css|svg)$`, resolved inside `UI_DIR` with a realpath containment check. It stays one path segment, `no-store` caching is unchanged, and it remains gated by `_peer_trusted`.
3. `check_panel.py`:
   - scan every shipped `.js`;
   - parse `STRINGS` from `core.js` (adjust the regex);
   - keep the retired-vocabulary scan and the deliberate `dedicated_device: 'Branch CT'` alias line;
   - keep the bans on inline script, external URLs, `eval`, `new Function` and `document.write`;
   - fail when an `import` names a missing module.
4. `validate_addon.sh`: `node --check` each module with `--input-type=module`.
5. `panel_harness.py`: load the modules via node `import()` with a DOM shim on `globalThis`. Convert the ~53 substring-slice sites (`script.index("function X(")`) in `test_panel.py` and `test_panel_data.py` to module imports.

## Tests
- All existing panel tests green against modules.
- New tests:
  - the gateway refuses `/ui/..%2Fgateway.py`, `/ui/sub/x.js` and unknown extensions;
  - `check_panel` fails on an inline `<script>` and on a dangling import.
- The Playwright e2e (skip-if-absent) loads under a fake ingress prefix.

## Traps
`Cache-Control: no-store` re-fetches every module through ingress on each load. Keep the module count ≤ 14.
