# K05 — Matrix contracts: MappingCell v3, column and row trees, drill-down payloads

**Wave:** 1 · **Depends on:** K00 · **Size:** M · **Decisions:** DEC-27, 29 · **Interfaces:** §8 · **Analysis:** `analysis/E-mapping-matrix-ui-ha.md` §1, C1–C5

## Objective
Structured cells per HB §9.6, the HB §9.7 vocabularies, the L0–L4 column tree with annotations, the row tree with special row kinds, and the drill-down payloads for HB §19.4.

## Owns
- `engine/wattmosaic_engine/contracts/matrix.py`
- its generated schemas
- new `tests/unit/test_contracts_matrix.py`
- new `tests/fixtures/matrix/hb17_payload.json`: a hand-written, valid `MatrixPayload` for the HB §17 house. U1 builds against it before M3 exists

## Steps
1. Implement `interfaces.md` §8 contracts: `MappingStatus`, `RowKind`, `CellVisual`, `CellMapping`, `CellPower`, `CellEvents`, `CellProvenance`, `CellTimestamps`, `MappingCell`, `ColumnAnnotation`, `ColumnNode`, `RowNode`, `ReaderColumnSummary`, `PhysicalTotal`, `MatrixPayload`, `CellDetail`, `ReaderDetail`, `RowDetail`.
2. Validators:
   - estimate inside bounds (port `_bounds_bracket_the_estimate` from `legacy.py`);
   - observability `NOT_OBSERVABLE` or `UNKNOWN` ⇒ no `estimated_power_w`;
   - a `GROUP_ONLY` visual ⇒ `estimated_power_w is None` on member cells;
   - `ColumnNode.kind == "reader"` ⇔ `reader_id` set ⇔ no children;
   - reader ids are unique across all leaves of `MatrixPayload.columns` (AT-13 at contract level);
   - `SUMMARY` rows ⇒ `derived=True`.
3. `MappingStatus` contains **no** identifiability values. Identifiability is its own field (`analysis/E-…` C1).
