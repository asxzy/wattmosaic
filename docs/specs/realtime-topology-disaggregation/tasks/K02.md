# K02 — Measurement and event contracts

**Wave:** 1 · **Depends on:** K00 · **Size:** M · **Interfaces:** §3 · **Analysis:** `analysis/B-realtime-pipeline.md` §1, C7; `analysis/A-…` C5, C12

## Objective
Implement the HB §2.1 `ReaderMeasurement`, the device-free `HAEvent`, the stage-4/5/6 records (`MeasurementEvent`, `EventEvidence`, `SubEvent`, `ReaderDelta`, `EventGroup`) and their lifecycle enums.

## Owns
- `engine/wattmosaic_engine/contracts/measurement.py`
- its generated schemas
- new `tests/unit/test_contracts_measurement.py`

## Steps
1. Implement `interfaces.md` §3 exactly.
2. Validators:
   - `onset_lo <= onset_hi`;
   - `EventEvidence.finalized=True` freezes nothing in Pydantic, but `with_sample()` returns a *new* record id (immutability by construction);
   - `EventGroup.revision >= 1`;
   - `ReaderDelta.completeness == "missing"` ⇔ `delta_w is None`.
3. `HAEvent.event_id` is a content hash of (entity_id, observed_at, to_state, sorted attributes_delta). Provide `HAEvent.make(...)`.
4. `MeasurementEvent.event_id` is a content hash of (reader_id, onset_lo, detector_version). Provide a helper.

## Tests
- Round-trip.
- Hash stability: same input gives the same id, and a different `to_state` gives a different id.
- A missing reader delta keeps `None` (never 0).
- `EventGroupStatus` covers the six HB §12.3 states in order.
