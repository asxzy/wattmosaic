# L1 — Power-model codec, registry v2, append-only version lifecycle

**Wave:** 3 · **Depends on:** K06, S18 · **Size:** L · **Decisions:** DEC-31, DEF-02, DEF-07 · **Interfaces:** §5 registry · **Analysis:** `analysis/F-power-models-learning.md` C2, C3, C5, WP-F1, §5 T1

## Objective
- A lossless codec (`decode(encode(m)).predict == m.predict`).
- A registry that implements `ModelSetView` with exactly one active version per subject.
- Append-only versions and an event log; rollback never reactivates a rejected or never-active version.
- One prediction path; delete the second, parameter-only interpreter.

## Owns
- `engine/wattmosaic_engine/models/serde.py`, `models/registry.py`, `models/protocols.py`
- new `engine/wattmosaic_engine/models/spec.py`, `models/prediction.py`
- `engine/wattmosaic_engine/core/models_api.py` (from X03)
- new `engine/wattmosaic_engine/api/routes/models_v3.py` (`GET /models/{subject_id}`)
- new `tests/unit/test_model_codec.py`, `tests/unit/test_registry_v3.py`

## Steps
1. Codec per spec kind (K06), with a `schema_version` check. Reading a newer schema raises clearly, never with silent defaults.
2. `Registry(model_repo, clock)`:
   - `active_set() -> ModelSetView` with `model_set_id`;
   - `predict` returns `PowerPrediction(status=UNKNOWN, mean_w=None)` when the level is unknown. **Never 0.0** (the fallbacks in `binary.py:168,191-194`, `dimmable.py:122,127`, `multi_state.py:115`, `time_varying.py:238` are not ported);
   - `transition_prior`, `expected_window`;
   - an atomic swap on promotion (keep the version-keyed LRU idea, `registry.py:56-75`);
   - freeze blocks promotion, not inference (product contract, `registry.py:157-159`).
3. Lifecycle API: `propose(version)`, `activate(version_id, reason)`, `reject`, `rollback(subject_id)` (the last `activated` in the log), `freeze`/`unfreeze`. All of them append.
4. `electrical/models.py` `expected_power_w`/`resolve_model` (`:127-170`, `:268-312`) is no longer called on the v3 path; Z2 deletes it.
5. DEF-01 follow-up: if P1 confirmed the polarity defect, mark versions trained on the affected readers `superseded` with reason `polarity_defect` (a migration-free event-log append).

## Tests
- A round-trip property test for every spec kind on a context grid.
- Explicit DEF-02 regressions: the component sum keeps its submodels; adjustable keeps `control_variable` (a `brightness_pct` query is not scaled 2.55×).
- Rollback never returns a REJECTED or never-active version (DEF-07).
- One active version per subject across a class change.
- An unknown level gives `None`.
- `model_set_id` changes iff the active set changes.
