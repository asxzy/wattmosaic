# S19 — Migration v019: per-reader residual series, unknown-load profiles

**Wave:** 2 · **Depends on:** X05, K03 · **Size:** S · **Analysis:** `analysis/C-…` C5, §1 "Per-reader residual history" (DEF-05)

## Objective
Store the residual per reader and topology version, and Unknown Load Profiles as rows. Today `residual_power` has no scope key, and profiles exist only as an unused contract.

## Owns
- new `engine/wattmosaic_engine/storage/migrations/v019_residual.py`
- `engine/wattmosaic_engine/storage/repositories/residual.py` (from X05)
- new `tests/unit/test_v019_residual.py`

## Steps
1. DDL: `reader_residual_series` (PK `reader_id, at`; all `ReaderResidualPoint` fields; L3, aggregated by the existing aggregation tiers) and `unknown_load_profiles` (L4).
2. Legacy: `ALTER residual_power ADD legacy_scope TEXT DEFAULT 'scope_unknown'`. Never reinterpret those rows as per-reader.
3. Repository: `put_points(batch)`, `series(reader_id, since, until)`, `latest(reader_id)`, `put_profile`, `profiles(scope_endpoint_id=None, lifecycle=None)`.

## Tests
- Two readers' series stay independent.
- Legacy rows flagged.
- Profile round-trip.
