# Z2 — Remove legacy engine paths

**Wave:** 5 · **Depends on:** every Wave-4 task VERIFIED · **Size:** M · **Decisions:** DEC-14, 19–21 · **See:** `../architecture.md` §5

## Objective
Delete the code that the v3 path replaced, so that the handbook's rules hold structurally rather than by convention. After Z2, no production path can run the 5 s full solve, the greedy step credit, the per-member model split or the 0.0 placeholder.

## Owns (deletion and rewiring only)
- `engine/wattmosaic_engine/disaggregation/`:

  - `mapping.py`, `confidence.py`, `tiers.py`, `events.py` (`StepTracker`);
  - `isolation.py` (`group_events`);
  - `auto_placement.py` and `configuration.py`: projection into `branch_ct_ids`, which mapping edges replace.

  - `matrix.py`, `main_power.py`, `nesting.py`, `hierarchy.py`, `models.py` (parameter interpreter);
  - `panel_tree.py`: its consumers move to T1's display tree.
- `engine/wattmosaic_engine/models/`: `binary.py`, `dimmable.py`, `variable_speed.py`, `multi_state.py`, `time_varying.py`, `composite.py`, `residual_power.py` (install-wide path)

## Steps
1. Delete first, then run the full suite plus acceptance and fix the imports. Never restore removed behaviour to make a test pass. A failing test either pins legacy semantics (delete or rewrite it with a note in the PR) or reveals a v3 gap (report it to the owning task).
2. Keep `test_safety_invariants.py` and port it to v3 modules.
3. Add a static gate `tests/unit/test_no_legacy_paths.py`. It fails if any of these symbols is reachable under `engine/`:
   - `DisaggregationEngine`
   - `power_w_is_placeholder`
   - `_group_bounds`
   - `_detect_ambiguity`
   - `StepTracker`
   - `branch_ct_ids`
   - `parent_ct_id`
   - `expected_power_w`
   - `infer_model_type`
   - `inference_interval_s`
