# L8 — Active-learning suggestions (optional)

**Wave:** 6 (after V1) · **Depends on:** V1 · **Size:** S · **Decisions:** DEC-36 · **Analysis:** `analysis/F-…` WP-F8

## Objective
A read-only ranked list of user actions that would most improve identifiability, for example "switch Living Room Light 1 on alone for one minute". It is never actuated.

## Owns
- new `engine/wattmosaic_engine/learning/suggestions.py`
- new `engine/wattmosaic_engine/api/routes/suggestions.py`
- new `tests/unit/test_suggestions.py`

## Steps
1. Score = uncertainty × expected identifiability gain (from the I4 null-space reduction if the member switched alone) × measurement impact ÷ user effort. Suppress safety classes (HVAC, garage door, water heater, DEC-36).
2. `GET /suggestions` (read-only). Panel rendering is a follow-up.

## Tests
- Two always-co-switched lights produce a "test independently" suggestion.
- A suppressed class never appears.
- A static test: no `call_service` and no HA write path is reachable from the module.
