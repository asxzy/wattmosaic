# K00 — Foundation contracts

**Wave:** 1 · **Depends on:** X01 · **Size:** M · **Decisions:** DEC-09, DEC-24 · **Interfaces:** §1 · **Analysis:** `analysis/A-…` C6, C8, C9

## Objective
Add the shared primitives every other contract task builds on:
- version id types and `VersionTriple`;
- `EvidenceRef`;
- `EstimateStatus`, `IdentifiabilityStatus`, `InferenceMethod`;
- `Bounds` with validators;
- the 7-component `ConfidenceVector` v3;
- the null-policy gate.

This task is **additive only**. Legacy models stay untouched until Z1.

## Owns
- `engine/wattmosaic_engine/contracts/foundation.py`
- `data/schemas/{version_triple,evidence_ref,bounds,confidence_vector_v3}.json` (generated)
- new `tests/unit/test_contracts_foundation.py`, `tests/unit/test_null_policy.py`

## Steps
1. Implement `interfaces.md` §1 exactly.
2. `ConfidenceVectorV3` components: `measurement_quality`, `event_association`, `model_fit`, `topology_consistency`, `identifiability`, `sample_coverage`, `freshness`. Each is `float | None` in [0,1]. There is **no blended scalar** field. Its docstring states it is not a probability (ADR-0007).
3. Version-id helpers: `topology_version_id(n) -> "topo-n"`, `parse_version_number(id) -> int`, `model_set_id(version_ids) -> "mset-<sha256[:12]>"` (sorted, deterministic).
4. `Bounds` validator: `lower_w <= upper_w`; a zero-width interval needs `allow_point=True`. That flag is set only by I5 for IDENTIFIABLE or MEASURED results; it is a private constructor path, not a public field.
5. Register every model in `SCHEMA_EXPORTS`.

## Tests
- Round-trip every model through JSON.
- `model_set_id` is order-independent.
- `Bounds` rejects inverted bounds and an unauthorised zero width.
- `test_null_policy.py`: walk every model exported from `contracts.foundation/entities/measurement/topology/inference/matrix/power_models`. No field named `*_w`, `*_kwh`, `*_wh`, `*_a`, `*_var` or `confidence` may have a non-`None` numeric default. The test applies automatically to K01–K06 models as they land.

## Rules
HB §18: an absent value is `None`. Never default a measurement or estimate to `0.0`.
